
\section{Introduction}

This document describes
a software library called
VSPLINE
that is available via electronic-mail
from NETLIB~\cite{netlib:87}.
The VSPLINE library contains a set of subroutines
that computes a non-parametric estimate
of a smooth vector-valued function
from noisy measurements,
both linear and nonlinear.
The algorithms are derived and described
in detail in~\cite{Fessler:91:lin,Fessler:91:non};
this documentation briefly outlines the main ideas
and explains the source code interface.
